Setup Guide

Complete these steps once before scanning Telegram channels.

  1. Open my.telegram.org and sign in with your Telegram account.
  2. Open API development tools and create or view your API ID and API Hash.
  3. Enter both values on this page, then enter your phone number in international format.
  4. Click Send Verification Code and enter the code received from Telegram.
  5. If requested, enter your Telegram two-step verification password.
  6. Confirm that the status says Connected, then return to Threat Intelligence to configure feeds.
Security: this page is intended for a local, trusted instance. API credentials are saved in the ignored backend/.env file; the Telegram session file stays on this machine. Never commit or share either file.

A verification code or two-step password is used only to complete the current sign-in and is not written to configuration or application logs.
